═══ 自定义超平坦图案 公式编写说明 ═══

一、格式

每层规则用分号 ";" 分隔。层规则有两种格式：

【普通格式】
  y=<起始>..<结束>: <表达式>
  y=<层>: <表达式>               ← 单层可省略范围

【let 代码块格式】
  y=<起始>..<结束>: {
    let 变量 = <表达式>;
    let 变量 = <表达式>;
    ...
    <最终表达式>
  }

  在 { } 内声明的局部变量可在后续 let 和最终表达式中使用。
  变量覆盖当前块的 x / z / ly 同名变量，退出块后恢复。

【循环格式】
  y=<起始>..<结束>: <厚度>*[<表达式>],<厚度>*[<表达式>],...

  在指定 y 范围内，按逗号分隔的组循环铺设：每组的厚度层使用对应表达式，
  组完一轮后从第一组重新开始，直到填满整个 y 范围。

  例：
  y=-64..64: 3*[minecraft:bedrock],2*[minecraft:dirt],1*[(x+z)%2==0 ? minecraft:white_concrete : minecraft:gray_concrete]

  效果：周期 6 层（3+2+1），从底到顶重复：3×基岩, 2×泥土, 1×棋盘格, 3×基岩... 直到 y=64。

默认预设：

  y=-64: minecraft:bedrock;y=-63..64: (x+z)%2==0 ? minecraft:white_concrete : minecraft:gray_concrete

【多维度（可选）】

  默认公式只作用于主世界。若要用公式改造下界 / 末地，用分节语法把各维度的
  规则分别包在 { } 里：

    {overworld=
      y=-64: minecraft:bedrock;
      y=-63..64: (x+z)%2==0 ? minecraft:white_concrete : minecraft:gray_concrete
    }
    {the_nether=
      y=0..5: minecraft:netherrack;
      y=6..120: seedhash(x, z, 1) < 0.5 ? minecraft:basalt : minecraft:blackstone
    }

  ★ 维度名：overworld（主世界）、the_nether（下界）、the_end（末地）。
    可写简写 nether / end，也可加 minecraft: 前缀。
  ★ 没写到的维度 = 按原版生成：下界/末地的生物群系、特征与结构照常生成。
  ★ 别名：{the_end=overworld} 表示末地复用主世界的公式；别名目标必须在本公式
    里显式定义（链式允许，如 {the_end=nether}{nether=...} 需 nether 节存在）。
  ★ 节与节之间允许空白或分号；节内仍用分号分隔各层。
  ★ 各维度用自己的高度：层范围超出该维度高度时自动截断（例如 y=-64..319 在
    下界只有 0..255 生效）；ly 始终是"该层声明的起点"算起的层内坐标。
  ★ 旧写法（不带 {}）完全不变：仅作用于主世界。

  【主世界按原版生成】新建世界时，如果公式里没有 overworld 节（例如只写了下界
  公式），创建出的世界主世界将使用原版地形生成；下界/末地按各自公式。已有世界
  不受影响（生成器在创建时固化）。想显式要（空/平）的主世界，就写一个 overworld 节。

  【须知】公式接管的是地形 / 表面 / 洞穴：生物群系、特征与结构（堡垒、末地城、
  矿物、植被等）仍按原版生成，会落进你的公式地形里。两点建议：
  · 末地建议自行绘制主岛区域——末影龙战、黑曜石柱等原版机制依赖主岛；
  · 不画基岩顶就没有顶（下界高度上限仍为 256）。
  · 新语法（分节/seed）在旧版本模组里会解析报错（图案停用）：用新版本创建的
    世界不建议降级打开。
  · v1.2.0 之前创建的"公式化生成"世界没有下界/末地维度（旧版一直存在的问题，
    传送门无法使用）：升级不会给已有世界补上，新建世界即可获得。

【结构与群系指令（可选）】

  在每个维度的公式内容开头，可以写方括号指令（顺序任意、可不写）：

    {the_nether=
      [structure:none]
      y=0..5: minecraft:netherrack;
      y=6..120: seedhash(x, z, 1) < 0.5 ? minecraft:basalt : minecraft:blackstone
    }
    {overworld=
      [structure:only=villages,strongholds] [biome:vanilla]
      y=-64: minecraft:bedrock;
      y=-63..64: (x+z)%2==0 ? minecraft:white_concrete : minecraft:gray_concrete
    }

  ★ [structure:...] 控制该维度的自然结构生成（默认 all = 全开）：
      [structure:all]              全开（默认，省略不写也是全开）
      [structure:none]             全关
      [structure:only=a,b,c]       白名单：只生成列出的结构
      [structure:except=a,b,c]     黑名单：除列出的外都生成
    名单里可写"结构组名"（villages、strongholds、mineshafts、nether_complexes、
    end_cities…）或"具体结构名"（village_plains、fortress、bastion_remnant…），
    两种写法可以混用；自定义/模组结构写 命名空间:名称（如 mymod:tower）。

  ★ 结构表（原版；标 * 的为 26.3 新增，旧版本写上去也不会生成、不会报错）：
    【主世界】villages 村庄 · strongholds 要塞 · ruined_portals 废弃传送门 ·
      mineshafts 废弃矿井 · desert_pyramids 沙漠神殿 · jungle_temples 丛林神庙 ·
      igloos 冰屋 · swamp_huts 沼泽小屋 · shipwrecks 沉船 · buried_treasures 埋藏的宝藏 ·
      ocean_ruins 海底废墟 · ocean_monuments 海底神殿 · pillager_outposts 掠夺者前哨站 ·
      woodland_mansions 林地府邸 · ancient_cities 远古城市 · trail_ruins 古迹废墟 ·
      trial_chambers 试炼密室 · abandoned_camp 废弃营地*
    【下界】nether_complexes 下界要塞+堡垒遗迹 · nether_fossils 下界化石 ·
      ruined_portals 废弃传送门（下界变体）
    【末地】end_cities 末地城

  ★ [biome:...] 控制该维度的生物群系（默认保持现状：主世界平原、下界/末地原版）：
      [biome:vanilla]          该维度使用原版群系分布（按坐标生成，与公式地形无关）
      [biome:minecraft:desert] 整个维度固定为指定群系
    使用 [biome:...] 后：群系专属结构（沙漠神殿、丛林神庙、冰屋…）会按群系自然生成，
    刷怪、天气、水色随群系变化；装饰特性（树/花草/矿物等）也跟随新群系照常生成
    （超平坦基座换群系后同样会生长原版植被）。只影响新生成的区块（已生成区块不变）。

  ★ [features:...] 控制该维度的群系装饰特性（树/花草/矿物/荧石/玄武岩斑块与石柱…；
    开或关都只留公式地形与结构，不细分具体装饰物）：
      [features:all]   装饰照常（默认，省略不写也一样）：写了 [biome:...] 时按新群系
                       生成原版装饰；没有群系规则时保持各维度原本行为（下界/末地照常，
                       超平坦基座本身就没有装饰）
      [features:none]  关闭全部群系装饰特性

  ★ 注意：
    · [structure:...] 只影响新生成的结构；/locate 与末影之眼仍按原版理论位置计算。
    · 主世界默认群系是平原，很多结构（如沙漠神殿）需要对应群系才会生成——
      想让它们都能出现，可以配合 [biome:vanilla]。
    · 用本版本"新建"的世界默认全部结构开启；本版本之前创建的旧世界，其结构
      覆盖表固化在存档里，[structure:...] 只能减少、不能增加。
    · 指令不写就保持旧行为，旧公式不受任何影响。


二、变量

  x    世界 X 坐标（整数，可正可负）
  z    世界 Z 坐标（整数，可正可负）
  ly   层内相对 y 坐标（从 0 开始，即 ly = 当前 y - 层起始 y）
  seed 当前世界的种子（整数；同一世界内恒定，不同世界一般不同）

       用 seed 可以让同一公式在不同世界呈现不同结果。注意：种子按 64 位保存，
       公式按双精度小数运算（约 53 位有效），仅低位不同的种子可能得到相同值；
       需要完整精度时请改用 seedhash()。


三、运算符

  算术：     +  -  *  /  %
  比较：     ==  !=  <  >  <=  >=
  逻辑：     &&  ||  !
  分组：     ( )

  三元条件： 条件 ? 值A : 值B


四、内置函数

  函数调用格式： 函数名(参数1, 参数2, ...)

  ── 整数运算 ──
  floordiv(a, b)   向负无穷取整除法，等价 Math.floorDiv(a, b)
  floormod(a, b)   向负无穷取模，结果始终 >= 0，等价 Math.floorMod(a, b)

  ── 通用数学 ──
  abs(x)           绝对值
  max(a, b)        取较大值
  min(a, b)        取较小值
  floor(x)         向下取整
  ceil(x)          向上取整
  round(x)         四舍五入
  sign(x)          符号函数（正数返回 1，负数返回 -1，0 返回 0）
  sqrt(x)          平方根
  pow(a, b)        幂运算 a^b
  exp(x)           e^x
  log(x)           自然对数 ln(x)
  log10(x)         以 10 为底对数

  ── 三角函数（参数 / 返回值均为弧度）──
  sin(x)           正弦
  cos(x)           余弦
  tan(x)           正切
  asin(x)          反正弦（返回值 -π/2 ~ π/2）
  acos(x)          反余弦（返回值 0 ~ π）
  atan(x)          反正切（返回值 -π/2 ~ π/2）
  todeg(rad)       弧度转角度
   torad(deg)       角度转弧度

   ── 随机 ──
   rand()                     从所有已注册方块（排除空气）中等概率随机选取一个
   rand(b1, b2, ...)          白名单模式——从指定的方块列表中随机选取
    randexcept(b1, b2, ...)    黑名单模式——从全部方块中排除指定的方块后随机选取

    ★ rand() 基于 (x, z, y) 坐标哈希生成"伪随机"值——同一坐标永远返回同一方块，
      不会闪烁变化。每个坐标的随机结果在创建时即确定且不会改变。
    ★ 注意：rand() 不使用世界种子——同一公式在任何世界的结果都一样。
      需要"随世界种子变化"的图案请用下面的 seedhash()。

   ── 种子散列 ──
   seedhash(a, b, ...)   把世界种子与全部参数（参数可为 0 个）做散列混合，
                         返回 [0,1) 的小数。同一世界、同一参数永远返回同一值；
                         不同世界一般不同——适合做"随世界种子变化"的噪声。

    ★ 例：seedhash(x, z, 0) < 0.5 ? minecraft:stone : minecraft:dirt
      （不同种子创建的世界图案不同；同一世界内完全确定、不会闪烁。）
    ★ 参数建议传整数格坐标（如 x、z 与通道号），便于构造格子类噪声：
      先 floordiv 到格子，再插值/多通道混合即可做光滑噪声。

   ★ 三角函数的参数单位是弧度。如需使用角度，用 torad() 转换：
     例：sin(torad(30)) = 0.5

   ★ 涉及格子类图案（/ 和 % 运算）务必使用 floordiv 和 floormod 替代 / 和 %，
     否则负坐标区域会出现异常尺寸的格子。详见第五节示例。


五、表达式示例

▸ 均匀层（所有坐标返回同一个块）：

  y=-64: minecraft:bedrock


▸ 1×1 棋盘格（相邻方块交替）：

  y=-64..64: (x+z)%2==0 ? minecraft:white_concrete : minecraft:gray_concrete


▸ 3×3 格子（大格子交替，无中心交换）：

  y=-64..64: (floordiv(x,3)+floordiv(z,3))%2==0 ? minecraft:white_concrete : minecraft:gray_concrete

  ★ 不能用 ((x/3)+(z/3))%2——负数除法向零截断，原点附近会形成 5×5 异常格子。


▸ 3×3 格子 + 中心交换（中心块取对面格子的颜色）：

  y=-64..64: (floordiv(x,3)+floordiv(z,3))%2==0
    ? (floormod(x,3)==1 && floormod(z,3)==1 ? minecraft:gray_concrete : minecraft:white_concrete)
    : (floormod(x,3)==1 && floormod(z,3)==1 ? minecraft:white_concrete : minecraft:gray_concrete)


▸ 沿 X 方向每 4 格换色（条纹）：

  y=-64..64: floordiv(x,4)%2==0 ? minecraft:white_concrete : minecraft:gray_concrete


▸ 沿 Z 方向的单格条纹：

  y=-64..64: (x+z)%2==0 ? minecraft:white_concrete : minecraft:gray_concrete

  注：1×1 棋盘格用 + 即可，不涉及 / 或 % 大数，无需 floordiv。


▸ 半径 20 格以内的圆形，圆形区域放白色，以外放灰色：

  y=-64..64: (x*x+z*z)<=400 ? minecraft:white_concrete : minecraft:gray_concrete


▸ 多色棋盘格（4 种颜色，按 x,z 奇偶）：

  y=-64..64: x%2==0 ? (z%2==0 ? minecraft:white_concrete : minecraft:red_concrete)
                   : (z%2==0 ? minecraft:blue_concrete  : minecraft:yellow_concrete)


▸ 正弦波条纹（灰度变化）：

  y=-64..64: (x+z*3)%6<3 ? minecraft:white_concrete : minecraft:gray_concrete


▸ 绝对值的图案（菱形区域）：

  y=-64..64: (abs(x)+abs(z))<=20 ? minecraft:white_concrete : minecraft:gray_concrete


▸ 正弦波条纹（连续灰度渐变，需搭配彩色块呈现）：

  y=-64..64: sin(torad(x*10))>0 ? minecraft:white_concrete : minecraft:gray_concrete

  每个周期约 36 格（360° / 10° = 36）。

▸ 正弦波 ：

  y=-61: abs(z - (sin(x / 5.0) * 5)) <= 1 ? minecraft:white_concrete : minecraft:light_gray_concrete

▸ 圆形波纹（同心圆）：

  y=-64..64: sin(sqrt(x*x+z*z)*0.5)>0 ? minecraft:white_concrete : minecraft:gray_concrete


▸ 循环层：3 层基岩 + 2 层泥土 + 1 层棋盘格交替（周期 6 层）：

  y=-64..64: 3*[minecraft:bedrock],2*[minecraft:dirt],1*[(x+z)%2==0 ? minecraft:white_concrete : minecraft:gray_concrete]


▸ 循环层：1 层白混凝土 + 1 层灰混凝土交替（每层都换色）：

  y=-64..64: 1*[minecraft:white_concrete],1*[minecraft:gray_concrete]

  效果与 (x+z)%2 棋盘格不同——这里是水平方向统一颜色，逐层交替。
  棋盘格是同一层内方块交替。


▸ 循环层 + 普通层混用：

  y=-64: minecraft:bedrock
  y=-63..64: 2*[minecraft:dirt],1*[(x+z)%2==0 ? minecraft:white_concrete : minecraft:gray_concrete]

  第 -64 层为基岩，第 -63~64 层按 2 泥土 + 1 棋盘格循环。


▸ 指定池随机：棋盘格白色部分随机替换为 3 种方块之一：

  y=-64..64: (x+z)%2==0 ? rand(minecraft:white_concrete, minecraft:dirt, minecraft:bedrock) : minecraft:gray_concrete


▸ 全方块随机（整个层从全部注册方块中随机抽取）：

  y=-64..64: rand()


▸ 条件随机 + 不同随机池：

  y=-64..64: (floordiv(x,4)+floordiv(z,4))%2==0 ? rand(minecraft:stone, minecraft:cobblestone) : rand(minecraft:oak_planks, minecraft:glass)


▸ 黑名单随机：从全部方块中排除石头、泥土、草方块后随机：

  y=-64..64: randexcept(minecraft:stone, minecraft:dirt, minecraft:grass_block)


▸ 立体模型（ly 用于 y 方向，配合 air 可实现镂空）：

  y=-64..64: (x+z)%2==0 && ly<10 ? minecraft:white_concrete : minecraft:air

  只在棋盘格的白色位置生成 10 层高的立柱，其余为空气。


▸ 随世界种子变化的图案（同一公式，不同种子的世界各不相同）：

  y=-64..64: seedhash(x, z, 0) < 0.5 ? minecraft:white_concrete : minecraft:gray_concrete

  做格子类噪声时先把坐标 floordiv 到格子，例如：
  y=-64..64: seedhash(floordiv(x,3), floordiv(z,3), 0) < 0.5 ? minecraft:white_concrete : minecraft:gray_concrete


▸ 多维度（主世界棋盘格 + 下界公式 + 末地复用主世界）：

  {overworld=y=-64: minecraft:bedrock;y=-63..64: (x+z)%2==0 ? minecraft:white_concrete : minecraft:gray_concrete}
  {the_nether=y=0..40: seedhash(x, z, 7) < 0.5 ? minecraft:basalt : minecraft:blackstone}
  {the_end=overworld}

  末地没有写公式内容，而是用别名复用主世界的公式（各维度仍按自己的高度范围）。


▸ let 代码块——避免重复计算，提升复杂公式可读性：

  y=-64..319: {
    let cellX = floordiv(x, 192);
    let cellZ = floordiv(z, 192);
    let cellSeed = cellX*37.1 + cellZ*91.7;
    let offX = sin(cellSeed)*40;
    let offZ = cos(cellSeed*1.3)*40;
    let dx = x - (cellX*192 + 96 + offX);
    let dz = z - (cellZ*192 + 96 + offZ);
    dx*dx + dz*dz < 400 ? minecraft:white_concrete : minecraft:air
  }

  将长公式中的重复子表达式提取为变量，逻辑清晰易维护。


六、块（Block）

块用标准 Minecraft 资源 ID 表示：

  minecraft:white_concrete
  minecraft:gray_concrete
  minecraft:bedrock
  minecraft:dirt
  minecraft:grass_block
  minecraft:stone
  minecraft:glass
  minecraft:cobblestone
  minecraft:oak_planks

支持的颜色混凝土（switch 常量，无需注册表）：
  white_concrete, gray_concrete, black_concrete, red_concrete,
  blue_concrete, yellow_concrete, green_concrete, orange_concrete,
  purple_concrete, light_gray_concrete, light_blue_concrete,
  magenta_concrete, lime_concrete, pink_concrete, cyan_concrete,
  brown_concrete

其他块通过 BuiltInRegistries.BLOCK 注册表查询。


七、组合示例

▸ 1 层基岩 + 10 层泥土 + 1 层草方块 + 117 层 3×3 棋盘格：

  y=-64: minecraft:bedrock;y=-63..-54: minecraft:dirt;
  y=-53: minecraft:grass_block;
  y=-52..64: (floordiv(x,3)+floordiv(z,3))%2==0 ? minecraft:white_concrete : minecraft:gray_concrete


▸ 循环层：基岩底 + 泥棋盘循环铺满 -63~64（3 泥土,1 棋盘格...4 泥土,1 棋盘格）：

  y=-64: minecraft:bedrock;y=-63..64: 3*[minecraft:dirt],1*[(x+z)%2==0 ? minecraft:white_concrete : minecraft:gray_concrete]


八、注意事项

1. 分号 ";" 必须在英文输入法下输入，中文分号 "；" 不能识别。
2. 所有 Minecraft 块 ID 必须在英文输入法下输入。
3. 嵌套三元条件时务必用括号明确优先级。
4. 格子类图案（涉及 / 和 %）必须使用 floordiv 和 floormod 函数，
    不能直接使用 / 和 % 运算符，否则负坐标区域会出现异常。
5. 不涉及大小判断的 % 运算（如 (x+z)%2）可直接用运算符，不受影响。
6. ly 变量用于层内偏移（如渐变效果），通常不需要使用。
7. 循环格式中方括号 [ ] 内可以是任意复杂表达式（含三元、函数等）。
8. 循环格式中的逗号 "," 用于分隔每组，方括号内的逗号不影响解析。
9. rand() 为伪随机——同一坐标永远返回同一方块，创建时确定，不会因进出
   世界而改变。rand() 的全池模式排除空气（minecraft:air）。
10. 建议在生成顶层为非超平坦的地形时将“生成结构”一项设为“关”。


九、专用服务器

专用服务器没有创建世界界面，无法用编辑器写入公式标记。请在
config/ohmyworld.json 中设置 server_mode: true，公式将应用于服务器上
所有超平坦世界（非超平坦世界不受影响）。server_mode 下修改公式约 5 秒
自动生效（仅影响之后新生成的区块），无需重启服务器。

  server_mode 的公式同样支持分节语法：写了哪个维度，哪个维度被接管；
  没写的维度保持原版。服务器端主世界生成器由 level-type 决定：想要
  "主世界原版 + 公式化下界/末地"，把 level-type 设为 normal（默认）并只写
  the_nether / the_end 节即可。
  ★ 运行中新增/移除维度节：需要重启服务器（单人游戏退出重进）才会对已有
    生成器生效；只改各节内的公式内容则约 5 秒自动生效。
  ★ 排查问题时，可以把 config/ohmyworld.json 的 "debug_logs" 设为 true：
    日志会输出每个维度的接管决定、公式 marker 的读写、主世界替换决定等
    诊断信息（默认 false，正常游玩无需开启）。
